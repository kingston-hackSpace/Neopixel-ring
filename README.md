<h1>Neopixel Ring</h1>

<p>The Neopixel ring is a small array of RGB LEDs. Each light can be individually addressed and sent different RGB data. The neopixel library allows each LED to be accessed through an array data structure. The lights can be altered in real time to allow for fast moving animations of colour. The rings come in a variety of diameters with different numbers of lights.</p>

<p>Neo pixel rings come in sizes of 12,16,24 and 60. Make sure to specify the number of LEDs in the neopixel declaration,</p>

<p>The neo pixel object has uses two methods to control the light effects use "setPixelColor" to set a chosen LED to a RGB value, then "show" to write the color changes to the ring.</p>

<p>muliple lights can be targeted using a for loop.</p>

<p>The library found here has examples of different effects that can be acheived with the neopixel rings.</p>
